# Personal Budget & Expense Tracker
## Week 2 HTML & CSS Project

This project is a Personal Budget and Expense Tracker created using HTML and CSS. It builds on my Week 1 project by adding an expense table, an upgraded form, multimedia content, interactive HTML elements, and advanced CSS selectors.

## index.html

The `index.html` file contains the structure of the Budget Tracker. It includes a heading and logo, an Add Expense form, a category dropdown, an expense table with five sample expenses, a collapsible instructions section, and an embedded budgeting video.

## style.css

The `style.css` file controls the appearance of the website. It styles the form, table, headings, button, multimedia section, and page layout. It also includes advanced selectors such as descendant selectors, direct child selectors, `:nth-child()`, `:focus`, `:hover`, and `:not()`.

## Expense Table

The expense table contains columns for Name, Amount, Category, and Date. Five sample expenses are included. Alternating row colors and a hover effect make the table easier to read.

## Add Expense Form

The form contains fields for the expense name, amount, category, and date. The category field uses a dropdown with Food, Transport, Rent, Entertainment, and Other options. The Add Expense button is currently visual only because JavaScript will be added later.

## Multimedia and Interactivity

The page includes a budget icon using the `<img>` element and an embedded YouTube video using an `<iframe>`. A `<details>` and `<summary>` section provides collapsible instructions for using the tracker.
