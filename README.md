# Personal Budget & Expense Tracker
## Week 2 HTML & CSS Project

This project is a Personal Budget and Expense Tracker created using HTML and CSS. It builds on my Week 1 project by adding an expense table, an upgraded form, multimedia content, interactive HTML elements, and advanced CSS selectors.

## index.html

The `index.html` file contains the structure of the Budget Tracker. It includes a heading and logo, an Add Expense form, a category dropdown, an expense table with five sample expenses, a collapsible instructions section, and an embedded budgeting video.

## style.css

The `style.css` file controls the appearance of the website. It styles the form, table, headings, button, multimedia section, and page layout. It also includes advanced selectors such as descendant selectors, direct child selectors, `:nth-child()`, `:focus`, `:hover`, and `:not()`.

## Expense Table

The expense table contains columns for Name, Amount, Category, and Date. Five sample expenses are included. Alternating row colors and a hover effect make the table easier to read.

## Add Expense Form

The form contains fields for the expense name, amount, category, and date. The category field uses a dropdown with Food, Transport, Rent, Entertainment, and Other options. The Add Expense button is currently visual only because JavaScript will be added later.

# Personal Budget & Expense Tracker

## Week 3: Visual Design Challenge

This project is a Personal Budget and Expense Tracker built using HTML and CSS. In Week 3, I improved the visual identity of the existing tracker by applying a consistent color palette, custom typography, improved table and form styling, and the CSS Box Model.

## Color Palette

The application uses a clean green-based color palette inspired by budgeting, money, and financial growth. Dark green is used for headings, buttons, and table headers, while soft green and neutral colors are used for backgrounds and supporting elements.

## Typography

The project uses Google Fonts. Merriweather is used for the main headings to create a strong visual hierarchy, while Inter is used for body text, labels, buttons, form elements, and table content for readability.

## Add Expense Form

The Add Expense form is presented as a visual card with padding, borders, rounded corners, and clear spacing. Inputs and the category dropdown have consistent styling, and focus states make it clear which field is currently selected.

## Expense Table

The expense table includes a colored header, cell borders, padding, alternating row colors, and a hover effect. These styles make the data easier to scan and improve the overall appearance of the tracker.

## CSS Box Model

Margin is used to separate major sections of the page. Padding provides space inside cards and form elements, borders define each section, and border-radius creates softer and more modern corners.

The page heading, Add Expense form, and Expense Table each appear as separate visual cards, making the application cleaner and easier to use.

The page includes a budget icon using the `<img>` element and an embedded YouTube video using an `<iframe>`. A `<details>` and `<summary>` section provides collapsible instructions for using the tracker.
